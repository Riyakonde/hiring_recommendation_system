# 🤖 AI Hiring Recommendation System

This Streamlit app analyzes a **candidate's resume** and a **job description** using **LangChain + OpenAI GPT** to generate an AI-based **hiring recommendation report**.

---

## 🚀 Features
- Enter your OpenAI API Key in the sidebar
- Upload Resume (PDF) & Job Description (PDF)
- Automatic Candidate Name Extraction
- AI Summaries & Matching Scores
- Skills, Experience, Education, and Overall Score
- Final Hiring Recommendation Report (Downloadable)
